# 訂單資料表結構（orders、order_items）

## 本文件包含的資料表

| 資料表 | 說明 |
| --- | --- |
| orders | 訂單主檔 |
| order_items | 訂單明細 |

## 版本管控歷程

| 版次 | 發行日期 | 修訂說明 | 修訂單位 | 修訂人員 |
| --- | --- | --- | --- | --- |
| 1.0 | 2026/11/10 | 初版 | 示範團隊 | 系統分析師 |

## 資料表：orders

### 欄位清單

| # | 欄位 | 型別 | PK | 說明 |
|:-:|---|---|:-:|---|
| 1 | id | INTEGER | ✓ | 訂單 id，自動編號 |
| 2 | order_no | TEXT | | 訂單編號，唯一 |
| 3 | member_id | INTEGER | | 所屬會員 id，對應 members.id |
| 4 | ordered_at | TEXT | | 下單時間，固定格式 YYYY-MM-DD HH:MM:SS（本地時間） |

### 索引

| 索引 | 欄位 |
| --- | --- |
| idx_orders_member_date | member_id、ordered_at |

### 各規格使用欄位對照

| 規格 | 使用欄位 |
| --- | --- |
| [會員匯出訂單 Excel](../orders-export.md) | order_no、member_id、ordered_at |

## 資料表：order_items

### 欄位清單

| # | 欄位 | 型別 | PK | 說明 |
|:-:|---|---|:-:|---|
| 1 | id | INTEGER | ✓ | 明細 id，自動編號 |
| 2 | order_id | INTEGER | | 所屬訂單 id，對應 orders.id |
| 3 | product_name | TEXT | | 商品名稱 |
| 4 | quantity | INTEGER | | 數量，大於 0 |
| 5 | subtotal | INTEGER | | 該項商品小計（整數元），大於等於 0 |

### 索引

| 索引 | 欄位 |
| --- | --- |
| idx_order_items_order | order_id |

### 各規格使用欄位對照

| 規格 | 使用欄位 |
| --- | --- |
| [會員匯出訂單 Excel](../orders-export.md) | order_id、product_name、quantity、subtotal |

## 關聯清單

| 子表 | 子表欄位 | 父表 | 父表欄位 | 關係 | 依據 |
| --- | --- | --- | --- | --- | --- |
| orders | member_id | members | id | 一對多 | 外鍵約束 |
| order_items | order_id | orders | id | 一對多 | 外鍵約束 |
